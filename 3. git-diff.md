## 1. Que es "git diff"?
**este comando nos ayuda a visualizar que modificamos en el codigo comparandolo con lo que hay en el ultimo commit del proyecto**

## 1. Que es "git diff --staged"?
**este comando nos ayuda a visualizar lo que modificamos en el código despues de agregar los cambios al staging y lo compara con el ultim commit del proyecto**

## 1. Que es "git show"?
**este comando nos ayuda a visualizar el ultimo commit pusheado junto con su hash, autor, hora, fecha, commit (asimismo git show nos permite buscar un hash en especifico git show [identificador-del-commit])**
