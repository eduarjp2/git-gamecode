## 1. Que es "git log"?
**este comando nos ayuda a visualizar desde el primer commit de nuestro proyecto hasta el ultimo, en el cual cada commit tiene un hash completo (40 caracteres) junto con su autor, fecha, y descripcion**

## 2. Que es "git log --oneline"?
**este comando nos ayuda a visualizar desde el primer commit de nuestro proyecto hasta el ultimo la diferencia es que este nos muestra de una manera más especifica solamente, el hash corto (7 caracteres) y mensaje del commit, esto hace que se más facil de leer el historial (en caso de que tengas muchos commits)**
